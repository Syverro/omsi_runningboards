Step-by-Step GitHub Pages Hosting Guide

1
Create GitHub Repository: Go to github.com → New Repository → Name it omsi-running-boards (Public).
2
Upload HTML File: Rename this exported HTML file to index.html and upload it directly into your repository.
3
Enable Pages: Go to Repository Settings → Pages → Set Branch to main / root → Click Save.
