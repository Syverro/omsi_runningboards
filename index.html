Deployment Guide: GitHub Pages

Follow these simple steps to deploy this standalone OMSI 2 Duty Card Generator onto GitHub Pages for team/virtual bus company (VBC) usage.

Step 1: Create a Repository

Create a new repository on GitHub named omsi2-duty-generator.

Step 2: Add Index File

Commit this entire HTML file as index.html in the main branch root.

Step 3: Enable Pages

Navigate to Settings -> Pages in your GitHub repository. Set Source to Deploy from a branch, select branch main, and click Save.
