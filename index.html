Deployment Guide: Host Free on GitHub Pages

Follow these steps to deploy this OMSI Duty Generator app to GitHub Pages free of charge.

Step 1: Create a GitHub Repository

1. Log in to GitHub.com and create a new public repository named omsi-duty-builder.

2. Leave "Add a README file" unchecked and create repository.

Step 2: Save and Push File

1. Save this entire page content as index.html.

2. Upload index.html directly to the root directory of your repository via the web UI or Git command line.

Step 3: Enable GitHub Pages

1. Navigate to Settings → Pages in your GitHub repository.

2. Under Build and deployment / Branch, choose main (or master) and folder / (root).

3. Click Save. Your app will be live at https://<username>.github.io/omsi-duty-builder/ in 1-2 minutes.
