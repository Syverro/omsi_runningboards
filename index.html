Hosting on GitHub Pages

  1. Create a repository on GitHub.com (e.g. omsi2-portal).
  2. Save this single HTML code as index.html.
  3. Commit and push index.html into the repository root.
  4. Go to Settings → Pages in your repository.
  5. Set source to Deploy from a branch and select main branch / (root).
