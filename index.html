Deploying to GitHub Pages

Follow these steps to host this web dashboard for free on GitHub Pages:

  1. Create a new repository on GitHub.com (e.g. omsi2-duty-card).
  2. Save this entire file code as index.html.
  3. Commit and push index.html into the root directory of your repo.
  4. Go to Settings → Pages in your repository.
  5. Under Build and deployment > Source, choose Deploy from a branch.
  6. Select main (or master) branch and folder / (root), then click Save.

In a few minutes, your OMSI 2 Running Board Studio will be online at https://yourusername.github.io/omsi2-duty-card!
