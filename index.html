Host Free on GitHub Pages

Deploy this single-file running board generator so drivers and planners can access it online.

1

Create a GitHub Repository

Log into GitHub, click New Repository, name it (e.g., omsi-running-boards), set visibility to Public, and click Create Repository.

2

Upload index.html

Click Add file $\rightarrow$ Upload files. Save this web app page code as index.html and commit it to the main branch.

3

Enable GitHub Pages

Navigate to Settings $\rightarrow$ Pages. Under Build and deployment, select Deploy from a branch, set Branch to main / root, and click Save.

Portal Live URL

Your portal will instantly be live at: https://<your-username>.github.io/<repo-name>/
