Host Free on GitHub Pages

  1. Create a repository on GitHub.com (e.g. omsi2-runningboard-portal).
  2. Copy this entire HTML file and save it as index.html in the repo.
  3. Commit and push index.html to your main branch.
  4. In GitHub repo, go to Settings → Pages.
  5. Select Deploy from a branch, set branch to main branch / (root).
  6. Click Save. Your live URL will publish automatically!
